# Student Task Management System

## Project Description

The Student Task Management System is a small browser-based web application created as part of a continuing DevOps practical project.

The application allows students to view existing tasks and add new tasks by entering a task title and description.

## Purpose

The purpose of this project is to demonstrate basic web development together with Git version control and later DevOps practices.

The same repository will be extended during future assignments using GitHub, Maven, Jenkins, Terraform, deployment and monitoring tools.

## Current Features

- Displays sample student tasks.
- Allows users to enter a task title.
- Allows users to enter a task description.
- Adds new tasks dynamically using JavaScript.
- Prevents blank task submissions.
- Provides a responsive and readable user interface.

## Project Structure

student-task-manager/

- index.html - Contains the structure of the web application.
- style.css - Contains the styling and responsive layout.
- script.js - Contains the JavaScript used to add and validate tasks.
- README.md - Contains project documentation.
- .gitignore - Defines files and folders that should not be tracked by Git.

## Usage Instructions

1. Open the project folder.
2. Open index.html in a modern web browser.
3. Enter a task title.
4. Enter a task description.
5. Click the Add Task button.
6. The new task will appear in the Student Tasks section.
7. Blank task submissions are rejected.
